# 学习通自动刷课脚本

一个 Tampermonkey 用户脚本：自动播放学习通课程视频、章节测验调用 DeepSeek 作答，并提供可拖拽的可视化控制面板。

## 功能

- 视频自动播放、静音、暂停恢复、播放结束自动进入下一节
- 章节测验自动识别单选题、多选题、判断题，调用 DeepSeek 生成答案并提交
- 视频播放中弹出的弹题会自动识别、暂停视频、作答、提交并继续播放；提交前会等待约 3 秒，降低被判定答题过快的概率；同一题重复弹出会复用缓存答案；未填写 API Key 时会暂停并提示，输入后自动继续
- 可视化面板：开始 / 停止 / 下一节、视频进度、章节状态、彩色日志
- 播放倍速 1.0–3.0x，可锁定，拦截页面把倍速改回 1x
- `自动答题` / `自动跳节` 开关、`识别题目`、`字体诊断`
- 字体反爬处理：优先解析页面字体 `cmap` / `post` 表还原文本；解析不到时用选项主题约束模型还原
- API Key 仅保存在油猴本地存储，只向 `api.deepseek.com` 发起请求

## 安装

1. 安装 Tampermonkey（Firefox / Chrome / Edge）。
2. 打开 Tampermonkey 面板 → 添加新脚本。
3. 全选并粘贴 `xuexitong-deepseek.user.js` 的全部内容，`Ctrl+S` 保存。
4. 打开学习通课程播放页，右侧会出现「学习通 · DeepSeek」面板。
5. 在面板顶部粘贴 DeepSeek API Key，点「保存」，脚本自动开始。

## 使用

- `开始` / `停止`：启动或停止当前页面的自动化。
- `下一节`：手动切换到下一学习步骤。
- 倍速下拉框：选择 1.0–3.0x；右侧「锁定」拦截页面重置倍速。
- `识别题目`：打印当前页面识别到的题目，便于核对。
- `字体诊断`：打印题目卡片的字体、`::before` / `::after` 和属性，用于排查字体反爬。
- `自动答题` / `自动跳节`：关闭后对应动作会停下，等待手动处理。
- `Alt+Shift+D`：显示 / 隐藏面板。

## 注意

- 首次使用建议观察一轮完整流程，确认题目识别和提交结果正确后再无人值守。
- 题目文本可能被学习通的字体反爬替换；脚本会优先尝试字体解码，失败时由模型结合选项共同主题还原，仍不一致会停止提交。
- 平台页面结构更新时脚本可能停在对应步骤，面板日志会给出原因。
- 模型答案可能出错，重要测验请自行核对。
